    Weekly Device Sweeps¶

    Every week the catalogue gets a short sweep: a few devices from the backlog become validated specs, and the news since the last sweep is searched for devices that are newly dying (cloud shutdowns, bankruptcies, withdrawn apps, new paywalls, firmware that removes local access) or newly popular, where local control is reasonably achievable. The backlog is Missing Devices; this page is the dated log on top of it.

    Like the survey, each entry is a snapshot. Grep device-specs/devices/, research-notes/ and targets/ before starting on anything listed here. Claims marked unverified rest on a search snippet or a page that would not load, and need checking before they go into a spec.

    2026-10-11¶

    Added this week¶

    Four of the survey's Do these next picks:

    Spec Survey item Notes
    AM43 / A-OK Blind Motor #2 Every frame checked against the XOR rule; six match literal frames in am43-ctrl; scripts/test_am43_spec.py. No BLE command to set travel limits is public.
    Instant Pot Smart Bluetooth #1 Follows OpenPot's code where its README disagrees; every disagreement is in remaining_unknowns. scripts/test_instant_pot_spec.py.
    TiVo Network Remote #17 TCP 31339 remote only; Mind RPC is out of scope. TiVo's own PDF is offline, so facts come from openHAB and McBrine's client.
    Drobo NAS Status Daemon #15 Read-only. The 16-byte header layout rests on one owner's reading of a single 5N2.

    One caveat on the survey's rows, found while writing them: the AM43 row says the Blind Engine app is off Google Play, which could not be confirmed either way. The Drobo row's "liquidated in 2023" is the Chapter 7 conversion of April 2023; the fuller timeline is Chapter 11 in June 2022 and the end of sales and support on 27 January 2023.

    Status changes to items already listed¶

    • Neato Botvac: heise reported the cloud phase-out in the week of 2025-10-06 (heise), earlier than the survey's late-December date. Vorwerk's exchange programme (a Kobold VR7 for EU owners who bought since May 2023 and used the cloud features) is on Neato's own support site.
    • Melnor RainCloud: Home Assistant 2026.10 removed the integration because the cloud no longer responds (release notes), confirming the survey's April 2026 date.
    • SolarEdge: the same release dropped SolarEdge Local and added a core SolarEdge Modbus integration, which backs the survey's "Modbus TCP is the durable path". The entry should be re-scoped to Modbus.
    • Tesla Powerwall: a 2026-09-17 community report says local interfaces were disabled on the customer Wi-Fi after a Powerwall 2 to 3 swap (HA community); firmware version not given.
    • Sleep Number: the sale to SNBR Inc., an affiliate of Sleep Country Canada, was approved 2026-07-20 and closed 2026-07-31 (Davis Polk); the new owner's plans for the SleepIQ cloud are unknown.
    • Owlet Smart Sock 2: Owlet's own page now confirms the 2025-04-08 cutoff (Owlet support).
    • Wallbox: the restructuring plan became final in July 2026 after a new equity raise, easing the going-concern risk the survey cites.
    • Sense monitor (research-notes/sense-monitor.yaml): Sense's own help centre says consumer monitor sales ended 2025-12-31 or when stock ran out. Still cloud-only, so the note's verdict does not change.
    • TiVo: one-button and automatic SkipMode end 2026-11-02 in favour of a paid add-on with a 30-day trial (trade press, September 2026); the network remote is unaffected.
    • Enphase Envoy: a June 2026 Enphase community thread reports /api/v1/production and /api/v1/consumption stalling on firmware D8.3.5528 (an Envoy-S Metered, upgraded 2026-06-14; the page itself renders only as an error shell, so the detail is from the search snippet). The spec was observed on D8.3.5427; check on the next verification session.
    • Accell group (Haibike, Ghost, Raleigh, Lapierre, Winora) was declared bankrupt on 2026-08-11. Their bikes use Bosch, Yamaha or Shimano drives, so the drive specs are the relevant coverage.

    No local path¶

    Added this week¶

    Five more of the survey's Do these next picks, one of last pass's new candidates, and one research note graduated. Every spec is testing: untested; byte-level facts from client code are reported.

    Spec Survey item Notes
    Enel X Way JuiceBox #3 Plaintext JuiceNet UDP (v09u Gen 2, v07 Gen 1): 25-field status grammar, CMD reply with its 16-bit hash and base-35 check digits, telnet console on TCP 2000, three re-point routes (DNS override, router DNAT, telnet) each staged behind the SoftAP join. Both current commands advanced behind a safety_advisory: the charger clamps to its rating, not the wiring. The encrypted v09e/v08 firmware (June/Nov 2024) is recognised, not decoded. scripts/test_enel_x_juicebox_spec.py.
    Sengled Wi-Fi Smart Bulbs #5 Unauthenticated UDP 9080 JSON control (power, brightness, RGB, colour temperature 1-100, discovery broadcast); the setup-AP exchange at the bulb's fixed SoftAP address under RC4 with a fixed public key (device_encrypted); the stand-in-cloud replies and the wifielement/<MAC>/… MQTT vocabulary for a user-owned broker.     Yummly Smart Thermometer #7 XW2 (T1 dock + P1 probe): TLV service, one-byte challenge ping, probe frames with a reversed MAC, bit-rotation packing (20-bit core in 0.1 °F, 12-bit body in whole °F, 4-bit battery gauge) with 15 worked vectors, computed from the algorithm and labelled hypothesis.     Kano Coding Wand #16 Kano's own @kano/devices-sdk (MIT, npm, 2018) survives and names every UUID, so openness: documented_api; it settles the quaternion order (int16 LE, w x y z, ×1000) where two community clients disagree. Button, battery, vibration, RGB565 LED, keep-alive, orientation reset, magnetometer calibration, raw temperature, Nordic Secure DFU with both entry writes advanced. Administration 2023-06-06 (Gazette). Gesture recognition out of scope. scripts/test_kano_coding_wand_spec.py.
    Hot Wheels id Race Portal #18 Read-only: HWiD name, three services under one base UUID, indications for car UID, serial, NDEF car-ID token (21 bytes, base64url) and a float32 pass value whose physical unit is unconfirmed and stays raw. Mattel discontinued the id system 2023-12-31 (vendor FAQ). The authentication service is recorded as wire facts only. Laps are a client-side derivation. scripts/test_hot_wheels_id_race_portal_spec.py.
    Bose Sleepbuds II last pass's candidate One peripheral per bud: 12-byte Audio Data frame (play, stop, volume, timer), stored-sound list, clock sync, Settings flags and phone-free toggle, battery, Control Point opcodes (play-in-future, alarms, firmware queries). Sound upload and firmware activation under out_of_scope only. Link-layer security unknown at low confidence; the name matcher is low-confidence because no source recorded the factory name.     QardioArm (A100) graduated from research-notes/qardio-arm.md SIG Blood Pressure service with a full SFLOAT, flags and status decode; vendor control bytes for start and cancel; Just-Works bond with the four ATT error codes that mean re-bond; pinhole bond reset as factory_reset and unpair. Medical safety_advisory. The original note's dates were loose: the app vanished about 2024-09-21 and returned, servers were intermittent from 2025-03-12 and down for good 2025-04-29. The research note stays as the dated trail. scripts/test_qardio_arm_spec.py.

    Three schema gaps surfaced while writing them. One was closed in the same PR after review: advanced was not a declared key on network commands, so the JuiceBox current-limit flag validated only because command objects are open; the schema now carries the same advanced / advanced_reason contract there as on BLE commands and HTTP endpoints. Two remain, noted in the specs' remaining_unknowns: format.type has no float (Hot Wheels speed, Yummly XW3), and the BLE command vocabulary cannot express RGB565 packing (Kano set_color is unbound). Candidates for spec-evolution.
