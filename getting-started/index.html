    Getting Started with IoT Reverse Engineering¶

    So you've got an abandoned IoT device and you want to figure out how it works. Welcome to the club.

    Prerequisites¶

    • Curiosity and patience (lots of both)
    • A device to reverse engineer
    • A computer with Bluetooth and/or WiFi
    • Basic understanding of networking concepts

    The General Process¶

    1. Research -- Find everything you can (FCC filings, teardowns, forums)
    2. Capture -- Record traffic between the device and its original app/cloud
    3. Analyze -- Figure out the protocol structure
    4. Document -- Write it up using our device template
    5. Implement -- Build open source tooling to replace the proprietary stuff
